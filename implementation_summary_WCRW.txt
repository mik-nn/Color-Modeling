## 🚀 PROPOSED APPROACH TO ACHIEVE dE95 < 2.0 WITH 3 INPUT VARIABLES
We hypothesize that we can predict the full profile from only 3 anchor measurements:
1. Paper anchor (L*, a*, b* ≈ paper white)
2. Anchor 1: along dominant direction 1 at a fixed chroma (e.g., 30)
3. Anchor 2: along dominant direction 2 at a fixed chroma (e.g., 30)

The idea is to use these three anchors to compute anchor residuals (difference between reference and target in substrate and ink latent space) and apply a fine-tuning correction to the CAE prediction.

### Steps for the user to implement and test:
1. **Modify TransferView.tsx** to use a custom anchor set when a flag is set (or create a new predictor option).
   - For a given reference and target WCRW profile:
     a. Compute the paper Lab of reference and target (we already have this).
     b. Choose two angles from the list above (e.g., 45° and 165°).
     c. Choose a chroma value (experiment: start with 20, 30, 40).
     d. Compute desired Lab for anchor 1: paper_Lab_ref + [chroma * cos(angle1), chroma * sin(angle1)].
     e. Compute desired Lab for anchor 2: paper_Lab_ref + [chroma * cos(angle2), chroma * sin(angle2)].
     f. Find the patches in the reference profile that have Lab values closest to these desired Lab values (using Euclidean distance in Lab space).
     g. Use these two patch indices plus the paper patch index as the three anchors.
2. **Run the CAE predictor with anchor fine-tuning** (already implemented) using these three anchors.
3. **Compute the error metrics** (median ΔE00, P95 ΔE00, fraction ≤1.5) for the held-out WCRW profiles.
4. **Iterate** on the choice of angles and chroma value to minimize the error.

### Expected outcome:
With well-chosen anchors, we expect the anchor fine-tuning to correct the systematic errors in the CAE prediction, reducing the P95 ΔE00 from ~5.3 to potentially below 2.0.
